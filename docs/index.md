# architekton-py-example

Example data-science project generated by politeuma/architekton-py and regenerated whenever the template changes.

This site is generated output: the
[architekton-py](https://github.com/politeuma/architekton-py) template renders
this project from its `example-answers.yml` (the `data_science` kind) and
republishes it whenever the template changes, so the pages show what the
template produces rather than hand-written documentation.

## Installation

```console
$ pip install git+https://github.com/politeuma/architekton-py-example.git
```


## Usage

```python
from architekton_py_example import __version__

print(f"Hello architekton_py_example {__version__}")
```
